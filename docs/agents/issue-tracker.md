# Issue Tracker: GitHub

Issues and PRDs for this repo live in GitHub Issues at:
https://github.com/yuwilson105/To-Do-List-Calendar

## When a skill says "publish to the issue tracker"

Use the `gh` CLI to create a new issue:

```
gh issue create --title "..." --body "..." --label "..."
```

## When a skill says "fetch the relevant ticket"

Use the `gh` CLI to read an issue:

```
gh issue view <number>
```

## When a skill says "update an issue"

Use the `gh` CLI to edit an issue:

```
gh issue edit <number> --body "..."
```
