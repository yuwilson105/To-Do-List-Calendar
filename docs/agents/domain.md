# Domain Docs

How the engineering skills should consume this repo's domain documentation.

## Before exploring, read these

- **`CONTEXT.md`** at the repo root
- **`docs/adr/`** — read ADRs that touch the area you're about to work in

If any of these files don't exist, proceed silently.

## File structure

Single-context repo:

```
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## Use the glossary's vocabulary

When naming domain concepts, use the terms as defined in `CONTEXT.md`. The canonical glossary for this project is also in `.kiro/specs/adhd-task-scheduler/requirements.md` under the Glossary section.

Key terms: Task, Time Block, AI Scheduler, Habit Model, Quick-Add Bar, Next Action Card, Focus Mode, Daily Briefing, Reminder, Cron Job, Streak, Pomodoro Timer.
